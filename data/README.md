# Data provenance and layout

This directory is not versioned except for this README and the frozen
split manifests in `splits/` (part of benchmark contribution C1).

## Source dataset: Digitize-HCD

- **Citation**: Ahmed, N., et al. "Digitize-HCD: A dataset for
  digitization of handwritten circuit diagrams." Mendeley Data, v2
  (2025-02-05). doi: [10.17632/rngcz5wtv8](https://doi.org/10.17632/rngcz5wtv8).
  License: **CC BY 4.0**.
- Single archive `Digitize-HCD Dataset.zip` (2,095,021,617 bytes).
  Downloaded 2026-07-18; sha256 verified against Mendeley's published
  hash: `1d57d8db58f7624711e0fba044928822739771fee744cdd6fa4e2a953a481596`.
  Note: Mendeley v1 and v2 reference the **same** archive file; v2 is a
  metadata revision.

### Archive contents (extracted to `digitize_hcd/extracted/`)

| Part | Contents |
| --- | --- |
| `Component Symbol and Text Label Data/Circuit Diagram Images/` | 1,277 photographs `circuit_<n>.jpg`, original resolution (≈2000 px sides) |
| `.../component_annotations.json` | COCO: 1,277 images, **18,600 component boxes**, **17 categories** (BJT-NPN, BJT-PNP, Capacitor, Diode, GND, I-AC, I-DC, Inductor, MOSFET-N, MOSFET-P, Op-Amp, Resistor, V-AC, V-DC, V-DC (one port), Wire Crossover, Zener Diode) |
| `.../text_annotations.json` | MMOCR-style: per-image text instances with polygon, bbox, and transcription (e.g. "5V") |
| `Component Port Location Data/<Class>/` | per-class component crops (`Input Images/`, e.g. 7,295 resistor crops), **port-location Gaussian heatmaps** (`Output Heatmaps/`; multi-port classes such as Op-Amp have one subdirectory per port), and pixel port coordinates (`XY Coordinates/*.txt`) |

The COCO `images` entries carry only `file_name/height/width/id` —
**no drafter/writer metadata exists**, so drafter-disjoint splitting is
not possible; splits are stratified instead (see below). This is a
stated limitation of the benchmark.

## Local copies and reconciliation

`reconciliation.json` (generated by `scripts/reconcile_data.py`) records
sha256-level reconciliation performed 2026-07-18:

- `raw/` (1,277 files) is **byte-identical** to the published Circuit
  Diagram Images: 1,277/1,277 matched, 0 local-only, 0 published-only,
  0 duplicates.
- `cleaned/` (1,277 files) are the preprocessed versions
  (deskew → shadow removal → binarize → crop → 512×512 canvas, see
  `scripts/preprocess.py`); zero byte-level matches with the published
  set is expected. Correspondence is by identical `file_name`.
- Earlier plan documents mentioned a 624 vs 1,279 count discrepancy;
  it does not exist in the current state — both directories hold
  exactly the 1,277 published images.

**Caution**: the published annotations are in ORIGINAL image
coordinates. `cleaned/` images were produced by a transform that was
not recorded, so annotations cannot be projected onto them yet.
Training/evaluation against published annotations must use `raw/`
until preprocessing records its transform.

## Frozen splits (`splits/`, versioned)

Generated by `scripts/make_splits.py` (seed 0) from the published COCO
annotations: **train 895 / val 192 / test 190** (70.1/15.0/14.9%),
stratified by component-count tertile × rarest-class-present. All 17
classes are present in every split (test-set support: min 44 =
MOSFET-P, max 470 = Resistor). Full per-split class distributions:
`splits/splits_meta.json`.

## Other subdirectories

- `detections/` — per-image detection cache (`<stem>.json`), written by
  `scripts/detect_batch.py` / the pipeline's detect stage.
- `gt_netlists/` — ground-truth topology graphs (schema v1, see
  `src/schematic2netlist/gt.py`), bootstrapped by
  `scripts/annotate_topology.py` and human-verified (`verified: true`).
  `gt_netlists/renders/` holds verification overlays.
- `cghd/` — CGHD cross-dataset (Zenodo record
  [10056817](https://zenodo.org/records/10056817), CC BY 4.0,
  `cghd-zenodo-12.zip`, 3.4 GB) for zero-shot evaluation;
  `cghd/cghd_classes.json` is the upstream 53-entry class dictionary
  and `cghd/class_mapping.yaml` maps CGHD classes onto the 17
  Digitize-HCD categories.
