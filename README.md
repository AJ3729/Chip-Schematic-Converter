# schematic2netlist

**Photographs of hand-drawn analog circuit schematics → simulation-ready SPICE
netlists**, with a human-verified connectivity benchmark to measure it against.

Hand-drawn schematics are how circuits are first designed, taught and discussed,
yet they are disconnected from simulation: recreating each sketch in EDA software
is slow and error-prone. The obstacle is not recognizing the symbols — that is
nearly solved — but recovering the *wiring* between them, and there has been no
public ground truth on which to measure that.

```
photo ─► preprocess ─► component detection ─► text masking ─► wire extraction
      ─► node inference ─► terminal snapping ─► SPICE netlist ─► ngspice check
```

The pipeline is deterministic and fully local. Connectivity is treated
**topologically rather than geometrically**: wire pixels are grouped into
connected components (one component = one electrical node) and component
terminals are snapped to nodes. No OCR is performed; component values are
placeholders.

## Headline result

On **192 held-out circuits** that no parameter was ever selected on:

| metric | |
| --- | --- |
| strict end-to-end success (every net of every component correct) | **0.516** [0.448, 0.589] |
| net F1 | **0.877** |
| terminal-pair F1 | **0.808** |
| normalized graph edit distance (lower is better) | **0.182** |
| DC-solvable, before → after ledgered repair | 0.526 → **0.729** |

Every parameter was selected on a *separate* 190-image validation split. Running
the identical configuration on both shows no out-of-sample degradation, and the
two splits are matched on every difficulty proxy measured — see
[`results/split_swap/val_vs_test.json`](results/split_swap/val_vs_test.json),
regenerated by `scripts/compare_splits.py`.

**One caveat is measured rather than hidden.** The object detector was
early-stopped on the images that later became the test split, so its detection
metrics there are optimistic by **+0.017 mAP@0.5** against a split it never saw.
The topology cascade inherits that much. Both columns are reported side by side.

## Contributions

**C1 — a connectivity ground truth for Digitize-HCD.** 192 circuits, 2,564
components, 5,090 terminals, 1,497 nets. Every net traced from `null`, never
bootstrapped from pipeline output, with 2,047 intersection sites individually
adjudicated. The per-image decision record is released, so each netlist is
reproducible from its decisions rather than taken on trust.

**C2 — structural connectivity recovery.** A classical baseline solves *no*
circuit completely; the full configuration solves 0.516, with each of twelve
mechanisms ablated independently.

**C4 — a metric cascade** from detection through to strict end-to-end success,
with paired per-image bootstrap CIs and a deterministic (non-truncated)
graph-edit-distance bound.

**C5 — design-intent repair with an auditable assumption ledger.** DC solvability
rises 0.526 → 0.729 with **zero** circuits regressed and **zero** component net
assignments altered.

## Quick start

```bash
python -m venv venv && source venv/bin/activate
pip install -e '.[dev]'
```

`ngspice` must be on PATH (`brew install ngspice` on macOS).

```bash
python scripts/run_pipeline.py --image data/cleaned_1024/circuit_1199.jpg
```

Reproduce the paper's entire result set, then regenerate every table, macro and
figure from it:

```bash
python scripts/regen_on_split.py --split test --fill-caches
python scripts/make_paper_tables.py
python scripts/make_paper_figures.py
```

## Splits

Three frozen splits (seed 0, stratified by component-count tertile × rarest
class present): **train 895 / val 190 / test 192**.

The two evaluation splits **exchanged names on 2026-08-03**. Every tuned
parameter had been selected on the 190, which made any figure reported there
in-sample; the 192 never entered selection and now carry the fully verified
ground truth. No image moved between splits — only the labels did.

Consequently: **sweep with `--split val`, report with `--split test`.** Every
script takes `--split` with a default set by its role — exploratory and
selection scripts default to `val`, so nothing can leak into a reported number by
omission (see [`src/schematic2netlist/splits.py`](src/schematic2netlist/splits.py)).
Anything under `results/` dated before the swap is a validation number whatever
its filename says.

## Reproducibility

- Every run directory holds a `run_meta.json` with the full config, git SHA,
  seed and environment versions. That is what lets
  `scripts/regen_on_split.py` replay a historical ablation arm exactly rather
  than approximately.
- `seed` in the config seeds `random`, `numpy` and `torch`/Ultralytics.
- Configuration comparisons use a **paired** per-image bootstrap
  (`scripts/compare_runs.py`), not independent-CI overlap. The val-vs-test
  comparison is necessarily unpaired, and says so.
- Standing guards: frame-size guard (`schematic2netlist.frames`), detection-cache
  alignment (`scripts/check_cache_alignment.py`), data freshness
  (`scripts/audit_data_freshness.py`), and the no-hand-typed-numbers audit.
